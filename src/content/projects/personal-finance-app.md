## A problem close to home

Seeing a family member struggle with managing finances made me want to make financial organization more intuitive. It was a concrete problem I could turn into a design and software challenge.

## What I built

I designed a personal-finance management framework and built a web application around it. The goal was to make financial organization easier to understand and use.

This is a **self-reported build**. A public repository, screenshots, detailed feature inventory and live demonstration have not yet been added to this case study.

## What the process opened up

Building the app exposed more questions about the problem itself. What makes an interface intuitive? How can software make complex financial information understandable without hiding important details? What does someone need to trust a financial tool?

Those questions connect this practical project to my broader interest in financial infrastructure and human control.

## The case study is still taking shape

The implementation stack, testing record, specific design decisions and measured outcomes remain to be documented. I want to add the actual artifacts before making detailed claims about them.
