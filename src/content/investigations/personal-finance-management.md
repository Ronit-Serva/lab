## A practical starting point

Seeing a family member struggle with managing personal finances prompted me to look for a more intuitive approach. I wanted to turn an everyday difficulty into something I could address through design and software.

## From a problem to an application

I designed a personal-finance management framework and built a web application around it. The aim was to make financial organization easier to understand and use.

The connected project page describes the work so far. The application is available at [serva-aica.web.app](https://serva-aica.web.app/). Detailed workflows, screenshots and implementation choices will be added to the case study.

## The questions behind the interface

Building the application made the broader problem more interesting. How can financial information be clear without becoming oversimplified? What makes an interface feel intuitive? What does a person need to understand before trusting a financial tool?

These are questions the project raises, rather than claims of measured improvements or completed user research.

## What comes next

The next step for this case study is to document the actual application: its workflows, design decisions, implementation and lessons from building it. Those artifacts will make it possible to explain the approach in concrete terms.
